# 🗺️ Tourism Kiosk

An interactive, web-based tourism kiosk application built to provide users with an engaging digital guide experience. This project emphasizes intuitive UI/UX design and multimedia integration to showcase points of interest effectively.

## 🚀 Features
* **Interactive UI/UX:** Designed with a strong focus on usability and seamless navigation.
* **Web-Based Kiosk:** Optimized for displays, running cleanly locally or via a web server.
* **Dynamic Routing:** Powered by Python to serve various templates and static assets efficiently.

## 🛠️ Tech Stack
* **Backend:** Python
* **Frontend:** HTML5, CSS, and JS (via `templates/` and `static/`)

## 📁 Repository Structure
* `app.py`: The main application script handling routing and core logic.
* `templates/`: Contains the HTML structure for the interactive interface.
* `static/`: Stores CSS stylesheets, JavaScript, and multimedia assets.
* `Setup 101.txt`: Detailed initialization instructions and environment setup.

## ⚙️ Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/TariqAbhar/tourism-kiosk.git
   cd tourism-kiosk
   ```

2. **Review Setup Details:**
   Please refer to `Setup 101.txt` for specific environment configurations or dependencies needed for this project.

3. **Run the Application:**
   ```bash
   python app.py
   ```

4. **Access the Kiosk:**
   Open your web browser and navigate to the local address provided in the terminal (typically `http://127.0.0.1:5000`).
